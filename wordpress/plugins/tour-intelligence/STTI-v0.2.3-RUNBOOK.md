# STTI v0.2.3 — Fixture Promotion Runbook

## Purpose
Keep T1.1 fixtures immutable as evidence, while allowing an operator to create an editable private candidate from a fixture without retyping verified data.

## Expected runtime
- Tour Registry shows four read-only fixtures.
- Each fixture shows **Adaya Dönüştür** until converted.
- Clicking it opens Tour Editor with known fixture fields prefilled.
- Stable ID remains empty until **Private Kaydet**.
- First save allocates `STT-000001...`.
- Fixture remains unchanged.
- After conversion, Registry button becomes **Adayı Düzenle**.
- Duplicate conversion from the same fixture is blocked/redirected to the existing candidate.
- Public routes / sitemap / indexation / Homepage adapter remain OFF.
