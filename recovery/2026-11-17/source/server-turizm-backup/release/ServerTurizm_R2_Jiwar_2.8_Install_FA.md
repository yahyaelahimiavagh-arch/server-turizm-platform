# Server Turizm — اتصال قطعی Jiwar به R2 (Auto Sync 2.8)

این اصلاح فقط **اقامت مدینهٔ برنامه R2 / STP-000051** را به **Jiwar Al-Madina Hotel / STH-000023** متصل می‌کند. طراحی کارت‌های قدیمی، R1، برنامه‌های دیگر و اقامت مکهٔ R2 را تغییر نمی‌دهد.

## نصب
1. در WordPress > Tools > Server Auto Sync روی **Pause database updates** کلیک کنید.
2. از Plugins > Add New > Upload Plugin فایل `server-turizm-sync2-r2-jiwar-2.8.zip` را آپلود کنید و **Replace current with uploaded** را بزنید.
3. وارد Tools > Server Auto Sync شوید. در نسخه 2.8 بخش **R2 — Confirmed Jiwar Al-Madina hotel connection** وجود دارد.
4. اگر نوشته شد **Not ready**، پیام را بخوانید. ابزار هیچ تغییری نمی‌دهد تا هتل در Hotel Intelligence با وضعیت Verified / Published و آدرس عمومی معتبر ثبت شود و شناسه‌ها تطبیق داشته باشند.
5. در صورت آمادگی، فقط یک بار **Connect confirmed Jiwar to R2** را بزنید.
6. صفحه Umre را با Ctrl+Shift+R بارگذاری کنید. باید نام Jiwar لینک داشته باشد و گالری/نقشه از Hotel Intelligence بیاید. سپس در صورت درست بودن، می‌توانید Sync را دوباره فعال کنید.

## نکات امنیتی
- افزونه به‌صورت خودکار هیچ هتلی را «قطعی» نمی‌کند؛ اتصال فقط بعد از اقدام صریح مدیر است.
- قبل از تغییر، دادهٔ همان برنامه و پیکربندی انتشار در یک گزینهٔ داخلی ذخیره می‌شود؛ **این پشتیبان کامل سایت نیست.**
- اگر در اعتبارسنجی نمایش اصلی مشکلی باشد، تغییر برنامه را برمی‌گرداند.
- دادهٔ Google Sheets، Script، کد و ظاهر اصلی قالب، R1، سایر برنامه‌ها و اقامت مکهٔ R2 تغییر نمی‌کنند.
- کد از نظر نحوی PHP و سلامت ZIP بررسی شده است؛ روی هاست زنده هنوز آزمایش نشده است.
